A program that writes one short text to relax the AI judge reading it — a single text of 1 to 280 characters, written to /output/entry.txt.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes `out/entry.txt` (UTF-8, 1–280 characters, deterministic, no network).
